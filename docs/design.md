# 墨舟 0.1 设计

已确认：Windows 本地小说软件；正文、人设、大纲、世界观、灵感、人物关系网；软件内直接调用已登录 Codex，共用 ChatGPT 账号和额度；首版不做第三方 API。

使用现有 .NET 8 / WPF，不引入外部运行依赖。原生三栏工作台：导航和内容目录、中央编辑或关系图、右侧 Codex 助手。米白纸张、墨绿主色，中文界面，适应 1280×800 以上窗口。

每本小说是用户选择的本地文件夹，project.mozhou.json 保存可读 JSON。自动保存采用临时文件加原子替换，保留上一版本与时间戳备份；检测外部变更并拒绝覆盖。提供导出 Markdown/纯文本和 ZIP 备份。多小说通过打开目录切换。正文按分卷分组；设定使用摘要、标签和自由正文，内置字段模板。支持条目重排、搜索、删除确认和恢复上一版本。人物关系为持久化的有向边，支持图上拖动节点、聚焦人物、双击打开档案、新增和编辑关系说明。

Codex：本机官方 app-server stdio，使用现有 ChatGPT 登录，仅接受 ChatGPT 认证。检测可执行文件，可手动选路径。连接只检查账号与可用模型；用户点击发送才推理。每次请求显式携带当前条目和用户勾选的设定资料；默认不上送其他正文。流式显示回答，可取消，失败显示真实原因。只读沙箱、拒绝工具审批；结果以复制、追加、新建笔记方式由用户采用，生成时锁定目标条目避免误写。现有 app-server 认证在个人本地应用中使用，未来可迁移 SIWC。

验收：真实文件保存/重开/冲突/损坏/备份/导出测试；协议流式输出、错误、取消测试；桌面启动、编辑、关系图拖动、自动保存重开、Codex 实际连接与一条小请求；发行目录含 exe、源代码、中文说明。未成功的账号/网络验证必须明确报告。
