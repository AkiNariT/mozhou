墨舟 0.3 小说书架 · 2026-10-28

默认启动进入书架，用户选择小说后进入编辑器；命令行显式传入项目目录或主文件时仍可直接打开。
新建和打开过的小说自动入册，按最近打开排序。卡片显示书名、简介、章节数、正文估算字数和更新时间。
可按书名或简介搜索；无小说和无搜索结果有独立空状态。
顶部返回书架先保存并卸载当前项目；保存冲突、Codex 生成或连接期间阻止直接切换。
切换后清空未发送提示词，按小说目录加载各自对话，即使副本项目 ID 相同也不混用。
移出只修改书架索引，重新定位允许找回已移动的文件夹。损坏或仅有备份的小说保留入口，打开时沿用既有恢复流程。
首次迁移旧设置中的最近小说及 Library 直接子目录；已有索引（包括空列表）不重复迁移。
