墨舟 0.5.0 条目参考图 · 2026-11-02

功能
人设、世界观、正文、大纲、灵感条目均可附多张参考图。图库位于编辑器下方，可折叠。
多选导入 PNG/JPEG/BMP/GIF，GIF显示首帧；缩略图保留完整比例，点击打开适应窗口/缩放预览。
不支持文字段落内嵌图，不自动向Codex发送图片，不把参考图加入正文TXT/Markdown导出。

存储与兼容
相对引用保存在NovelEntry.Images；原图复制到小说assets/images，以随机文件名保存。
移除只解除关联，图片保留供历史恢复。完整ZIP包含管理图文件；另存副本先验证并复制资产，再保存当前内存草稿。
旧格式1没有图片时保持兼容；首次含图保存升级为2，防止旧版忽略新字段后覆盖。删除所有图后不降级。
缺失文件不阻塞小说加载/文字编辑，图库显示占位；备份和副本遇当前引用缺失会失败，不声称完整成功。
非法路径/重解析点拒绝访问；导出目标不能覆盖assets目录。图片名不包含外部原图绝对路径。

图像约束
导入上限25MiB、4000万像素。Desktop实际解码验证整批文件，复制后再次验证，才加入条目。
缩略图最长边360像素、预览2000像素，OnLoad并复制冻结像素，关闭文件句柄。
BMP/GIF的底层解码仍可能使用原尺寸内存；像素上限限制其峰值，不能视为消除所有解码内存开销。
损坏或不可读图片逐张显示占位。折叠、切换或返回书架释放缩略图；预览关闭清除Source。
