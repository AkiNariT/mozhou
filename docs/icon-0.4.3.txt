墨舟 0.4.3 朱砂折带图标 · 2026-10-29

设计
采用选定的 C「朱砂折带」方向：暖白圆角底、三片朱砂折面，书页与舟之间保留 S 形留白。
使用 AI 生成概念方案，再重新绘制可编辑 SVG，收整轮廓和透明外缘。
源文件不依赖字体、外部图片或在线资源。
源文件：Mozhou.Desktop/Assets/Mozhou.svg；导出：Mozhou.png（256px）、Mozhou.ico（10 帧）。

接入
沿用 ApplicationIcon、WPF Resource 和带程序集名的 pack URI。
EXE、主窗口、普通对话框、书架与编辑器页头共享同一个 ICO。
没有更改编辑、保存、书架或 Codex 业务代码，没有修改小说数据格式。

生成
Windows + .NET 8 SDK，无第三方包：
  dotnet run --project tools/GenerateIcon -c Release -- Mozhou.Desktop/Assets
可追加第二个参数输出预览 PNG。
工具支持当前素材使用的 path、linearGradient 与 matrix，不是通用 SVG 渲染器。
Geometry.Parse 的结果经 Clone 后设置变换，避免修改只读几何对象。
16、20、24、32、40、48、64、96、128 像素帧采用 32 位 DIB 与透明遮罩；256 像素帧采用 PNG。
